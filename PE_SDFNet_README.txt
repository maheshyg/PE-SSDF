# PE-SDFNet reference code

**STATUS: Newly written, unvalidated reference implementation. NOT original experimental code.**

This package is inspired by the manuscript *PE-SDFNet: Boundary-Aware Deep Learning for Precise Fetal Head Segmentation and Head Circumference Estimation*. It is not the code that produced the manuscript's reported performance, training curves, or ablation figures. **Do not submit it as proof of reproducing those results.** No experiments, evaluation, or clinical validation were conducted in creating this package.

## Components

- `model.py`: U-Net-style encoder/decoder, ellipse parameter prediction, implicit elliptical prior, signed-distance-field prediction, and feature fusion.
- `dataset.py`: paired ultrasound image and binary mask loading; median filtering, normalization, CLAHE, and resizing to 256 × 256.
- `train.py`: illustrative segmentation training using BCE, Dice, ellipse-prior, and smoothness losses.
- `predict.py`: binary mask inference using a genuinely trained checkpoint.
- `requirements.txt`: Python dependencies.

## Important methodological differences

The manuscript describes a **seven-term hybrid loss** with explicit SDF regression, Eikonal and physics-guided constraints. **This reference implementation does not implement all of those losses or the exact PGFR formulation**; its loss and fusion are simplified. It is therefore an illustrative starting point, not an exact implementation of the manuscript. The manuscript diagram uses channels 64, 128, 256, 512, and 1024; this package defaults to 32, 64, 128, 256, and 512 to reduce memory use. Use `--base 64` to match the diagram's widths. CLAHE settings are assumed and must be verified. The manuscript has inconsistent preprocessing orders across Methods and Figure 2; this code follows the Methods order.

## Installation

Python 3.10+ is recommended.

```bash
pip install -r requirements.txt
```

## HC18 data preparation

Dataset: https://doi.org/10.5281/zenodo.1322001

Download the HC18 data in accordance with the dataset terms. **No HC18 data or patient information are included.** The HC18 annotation format may require converting ellipse annotations into filled binary masks; conversion is not implemented because the original annotation files have not been inspected.

Provide your own non-overlapping split in the following structure:

```
data/
  train/images/  train/masks/
  val/images/    val/masks/
  test/images/   test/masks/
```

Image and mask filenames must match (e.g., `sample001.png` in both folders). Masks must be 0 for background and 255 for fetal head. The manuscript reports a 699/150/150 internal split of 999 annotated images, but exact split IDs, random seed and patient-level grouping have not been verified. Do not claim these splits are reproduced.

## Training

```bash
python train.py --train-images data/train/images --train-masks data/train/masks --val-images data/val/images --val-masks data/val/masks --epochs 200 --batch-size 8 --lr 0.0001 --base 32 --output best_model.pt
```

Use `--base 64` if sufficient GPU memory is available. A checkpoint is only generated by running training on actual paired images/masks.

## Inference

```bash
python predict.py --checkpoint best_model.pt --image data/test/images/sample001.png --output predicted_mask.png
```

This saves a segmentation mask, **not a clinically calibrated head circumference**. Circumference estimation requires verified physical pixel spacing and ellipse fitting in original-image coordinates; those steps remain to be implemented and validated.

## What is required before a journal reproducibility release

1. Implement and validate the complete manuscript equations and loss functions.
2. Record exact preprocessing settings, train/validation/test identifiers, seed, versions and hardware.
3. Run the actual experiments and preserve checkpoints, logs, raw predictions and numerical results.
4. Evaluate on a held-out test set and perform genuine ablation studies.
5. Regenerate all manuscript figures and tables from recorded results, not illustrative curves.
6. Document HC18 annotations, physical pixel spacing, and any ethical or licensing restrictions.

**No model accuracy, Dice, HD95, ASD, or HC-error claims are supported by this code package as supplied.**
